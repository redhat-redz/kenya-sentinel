# Initial Research Plan

## Proposed research question
Can a lightweight geospatial reporting and evidence-review prototype organize public infrastructure reports to support more consistent geographic analysis and maintenance prioritization in a defined study area?

## Objectives
1. Design a structured public-infrastructure report schema.
2. Implement a reporting workflow with geographic coordinates.
3. Visualize reports on an interactive map.
4. Evaluate a transparent geographic clustering method on a labelled dataset.
5. Measure the quality and limitations of the prototype.

## Research integrity
- Distinguish field observations from synthetic demonstration data.
- Record collection dates, methods and permissions.
- Do not claim national coverage from a local pilot.
- Do not claim predictive accuracy without a valid evaluation.
- Document sample size, class balance, limitations and error cases.
- Use human review for report credibility decisions.

## Initial evaluation measures
- API functional test pass rate.
- Report submission success rate under a defined test protocol.
- Clustering metrics only where data and distance metric make them appropriate.
- Classification precision, recall, F1 and confusion matrix if image classification is later added.
